# Contributing

Contributions and bug reports are welcome. Please open an issue describing the change before proposing large API changes.

For bugs, include your AIR SDK version, macOS and Xcode versions, iOS version, device model, build command, error output and minimal reproduction steps. Do not upload personal workbooks, provisioning files, signing certificates or private paths.

Pull requests should be focused, explain behavioral changes, and include physical-device test results if iOS native behavior is affected. A successful SWC compile on Windows is not proof of native iOS correctness.
